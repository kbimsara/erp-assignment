# ERP System

Design ERP system using PHP and MySQL to insert, update, delete and search system data.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You will need to have XAMPP installed on your machine. You can download it from [here](https://www.apachefriends.org/index.html).

### Cloning the Repository

1. Open your terminal or command prompt.
2. Navigate to the directory where you want to clone the repository.
3. Run the following command:

```bash
git clone https://github.com/your-username/erp-assignment.git
```

### Database Setup

1.  Start your XAMPP control panel and start the Apache and MySQL modules.
2.  Open your web browser and navigate to `http://localhost/phpmyadmin`.
3.  Create a new database named `erpdb`.
4.  Click on the `erpdb` database in the left-hand menu.
5.  Click on the `Import` tab.
6.  Click on the `Choose File` button and select the `erpdb.sql` file from the `DB ERp` directory in the project.
7.  Click on the `Go` button to import the database.

## Usage

1.  Move the cloned project folder to the `htdocs` directory in your XAMPP installation directory.
2.  Open your web browser and navigate to `http://localhost/erp-assignment/Web/`.
